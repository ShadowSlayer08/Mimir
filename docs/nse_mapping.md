# NSE Mapping

Maps services to the nmap NSE scripts the engine recommends for enumeration.
Defensive/enumeration scripts only — intrusive categories (`dos`, `exploit`,
`brute` beyond auth-checks) are intentionally excluded from the defaults.

```yaml
nse:
  http:          [http-title, http-headers, http-methods, http-enum, http-robots.txt]
  https:         [ssl-enum-ciphers, ssl-cert, ssl-heartbleed, ssl-poodle, http-title, http-headers]
  microsoft-ds:  [smb-protocols, smb-security-mode, smb2-security-mode, smb-os-discovery, "smb-vuln-*"]
  netbios-ssn:   [smb-protocols, smb-os-discovery, nbstat]
  kerberos:      [krb5-enum-users]
  ldap:          [ldap-rootdse, ldap-search]
  mysql:         [mysql-info, mysql-empty-password, vulners]
  ms-sql-s:      [ms-sql-info, ms-sql-empty-password]
  postgresql:    [vulners]
  mongodb:       [mongodb-info, mongodb-databases]
  redis:         [redis-info]
  memcache:      [memcached-info]
  elasticsearch: [http-title]
  oracle:        [oracle-tns-version, oracle-sid-brute]
  ssh:           [ssh2-enum-algos, ssh-hostkey, ssh-auth-methods]
  ms-wbt-server: [rdp-enum-encryption, rdp-ntlm-info, rdp-vuln-ms12-020]
  ftp:           [ftp-anon, ftp-syst, ftp-bounce]
  telnet:        [telnet-encryption, telnet-ntlm-info, banner]
  smtp:          [smtp-commands, smtp-open-relay, smtp-enum-users]
  imap:          [imap-capabilities]
  pop3:          [pop3-capabilities]
  domain:        [dns-nsid, dns-recursion, dns-zone-transfer, dns-cache-snoop]
  snmp:          [snmp-info, snmp-sysdescr, snmp-interfaces, snmp-processes]
  vnc:           [vnc-info, realvnc-auth-bypass]
  nfs:           [nfs-showmount, nfs-ls, nfs-statfs, rpcinfo]
  rpcbind:       [rpcinfo]
  winrm:         [http-ntlm-info, http-headers]
  ipmi:          [ipmi-version, ipmi-cipher-zero]
  modbus:        [modbus-discover]
  s7:            [s7-info]
  bacnet:        [bacnet-info]
  ethernet-ip:   [enip-info]
  jetdirect:     [pjl-ready-message]
  ipp:           [cups-info]
  tftp:          [tftp-enum]
  rsync:         [rsync-list-modules]
  x11:           [x11-access]
  ntp:           [ntp-info, ntp-monlist]
  finger:        [finger]
  sip:           [sip-methods, sip-enum-users]
  socks:         [socks-auth-info, socks-open-proxy]
  netconf:       [ssh2-enum-algos]
  afp:           [afp-serverinfo, afp-showmount, afp-ls, afp-path-vuln]
  iscsi:         [iscsi-info, iscsi-brute]
  rtsp:          [rtsp-methods, rtsp-url-brute]
  upnp:          [upnp-info]
  ws-discovery:  [wsdd-discover]
```
