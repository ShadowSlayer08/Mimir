# Service Registry

Maps discovered services to the assessment **modules** (workers) that handle
them. The dispatcher consults this table to decide which module(s) run for each
open port. Matching is by nmap service-name fragment (prefix / substring).

Edit the `registry` block to route a new service to a module — no code change.
